# Планировщик · ASTRA

Личный планировщик дня для Android 10 и новее. Дела, шаблоны, отметки и фотографии хранятся на устройстве. Аккаунт не нужен. Версия ASTRA (`ru.dayplanner.astra`) устанавливается отдельно от исходного приложения (`ru.dayplanner.app`).

## Скачать и установить
1. В [Actions → Сборка APK ASTRA](../../actions/workflows/build.yml) откройте последний **успешный** запуск на `main`. При необходимости войдите в GitHub, чтобы скачать артефакты.
2. В разделе **Artifacts** скачайте `scheduler-astra-НОМЕР` и распакуйте ZIP. Внутри — `app-debug.apk`. Архив `junit-НОМЕР` содержит результаты тестов, не приложение.
3. Откройте APK на телефоне. Если Android попросит, временно разрешите файловому менеджеру установку из этого источника. Обновления устанавливайте **поверх ASTRA**: удаление приложения удаляет локальные данные. При ошибке установки сохраните резервную копию; не удаляйте предыдущую версию ради обновления.

## Тёмная тема
Нажмите шестерёнку на экране дня → **Настройки → Тема приложения → Тёмная**. Переключать весь телефон в ночной режим не нужно. «Светлая» тоже действует независимо от Android, а «Как в системе» (по умолчанию) следует за настройкой телефона. Выбор сохраняется при перезапуске. В сборке № 11 и более ранних ручного переключателя нет: установите обновление.

## Пользоваться
- **День:** нажмите «+», чтобы создать дело на выбранную дату. Свайп меняет день, «Сегодня» возвращает к текущему. Календарь отмечает даты с делами. В карточке доступны фотографии, редактирование и удаление.
- **Типовые дела и повторы:** шаблон заполняет поля, но не выбирает время. Выполнение повторяющегося дела отмечается за конкретный день. При изменении серии проверьте выбор «Только этот день» или «Этот и все следующие».
- **Статистика:** выберите неделю или месяц; стрелкой перейдите к предыдущему периоду. Под диаграммой доступны числа по дням.
- **Стиль:** **Настройки → Стиль оформления**. «Обычный» — без похвалы и частиц; «С эффектами» добавляет их при выполнении дела. Оба стиля доступны и со светлой, и с тёмной темой.
- **Виджет:** удерживайте пустое место на рабочем столе → **Виджеты → Планировщик** и перетащите виджет. Заголовок открывает день, «+» — новое дело, строка — карточку. Размер меняется средствами лаунчера.
- **Сигналы:** задайте делу время начала или промежуток, включите нужный сигнал и выберите уведомление либо будильник. Android может отдельно попросить разрешения на уведомления, точные сигналы и полноэкранное окно. Без точных сигналов возможна задержка (включая обновление виджета после полуночи); при запрете уведомлений их не будет. Громкость, «Не беспокоить» и ограничения производителя также влияют на результат.

## Экспорт и восстановление
**Настройки → Резервная копия → Сохранить ZIP**. Выберите файл в системном диалоге. Архив содержит личные записи и фото в незашифрованном виде: не прикладывайте его к публичному issue. **Восстановить из ZIP** проверяет копию и после подтверждения заменяет все текущие дела, шаблоны, отметки и фото. Это не слияние. Перед восстановлением лучше сохранить текущее состояние в отдельный файл.

## Сборка и проверка
GitHub Actions собирает проект из `main` на `ubuntu-latest` при изменении кода или ручном запуске. Для подписанных сборок используется один зашифрованный debug-keystore и секрет Actions: **не для Google Play**, не менять для существующих установок. Инициализация проекта уже выполнена; для обычного обновления достаточно workflow сборки. Ключи, пароли и реальные пользовательские данные публиковать нельзя.

Модульные тесты проверяют сортировку, повторы, отдельные отметки по дням, метки календаря, статистику, время ближайшего сигнала, формат 24 ч и выбор темы. Это не проверка камеры, внешнего лаунчера или поведения Android в спящем режиме. [Сценарии проверки на телефоне](docs/Проверка-на-телефоне.md).
