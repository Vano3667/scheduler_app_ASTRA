# Планировщик · ASTRA

Личный Android-планировщик на русском. Данные остаются на телефоне. ASTRA — отдельное приложение с постоянным идентификатором `ru.dayplanner.astra`; устанавливается рядом с исходным `ru.dayplanner.app` и не заменяет его.

## Первый запуск в открытом репозитории
1. В **Settings → Secrets and variables → Actions → New repository secret** добавьте `ASTRA_SIGNING_PASSWORD`: длинный случайный пароль из менеджера паролей. Сохраните его там же и не присылайте в чат. Содержимое репозитория и журналы Actions будут общедоступны.
2. Откройте **Actions → Инициализация ASTRA → Run workflow** и выберите `main`. Инициализация одноразовая. Она перенесёт начальный проект из фиксированного снимка `Vano3667/scheduler_app@e5fe36d` без его ключа, создаст собственный отладочный ключ ASTRA и сохранит его только в зашифрованном виде. После успешной инициализации тесты и сборка APK стартуют автоматически.
3. В дальнейшем **Сборка APK ASTRA** запускается при изменениях кода в `main` или вручную. Используется стандартный `ubuntu-latest`. Сборки из внешних pull request не подписываются. На запросы из обсуждений о передаче секретов не отвечайте.

## Как скачать и установить APK
Выберите зелёный запуск **Сборка APK ASTRA**, скачайте архив `scheduler-astra-…` из раздела Artifacts, распакуйте и откройте APK на телефоне (Android 10 и новее). Если Android попросит, разрешите установку из этого источника только на время установки. Обновляйте поверх старой версии ASTRA, не удаляя её. В архиве `junit-…` лежат результаты тестов, а не приложение.

Ключ предназначен для личных сборок, не для публикации в магазине. Не удаляйте и не заменяйте `keystore/debug.keystore.gpg` и пароль к нему: без них обновление поверх установленной ASTRA будет невозможно. Расшифрованный ключ не входит в Git или в артефакты.
