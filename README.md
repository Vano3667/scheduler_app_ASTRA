# Планировщик · ASTRA

Личный Android-планировщик на русском. Данные остаются на телефоне. ASTRA — отдельное приложение с постоянным идентификатором `ru.dayplanner.astra`; устанавливается рядом с исходным `ru.dayplanner.app` и не заменяет его. Данные исходной установки автоматически не копируются.

## Установка и обновления
В Actions выберите успешный запуск **Сборка APK ASTRA**, скачайте архив `scheduler-astra-…` из раздела Artifacts, распакуйте и откройте APK на телефоне (Android 10 и новее). Если Android попросит, разрешите установку из этого источника только на время установки. Обновляйте поверх старой версии ASTRA, не удаляя её. Не путайте APK с архивом `junit-…`: в нём только результаты тестов.

Проект использует собственный отладочный `keystore/debug.keystore`: только для личных сборок, не для публикации. Не заменяйте ключ и не открывайте репозиторий. Код начальных этапов основан на снимке `Vano3667/scheduler_app@e5fe36d`; открытый ключевой контейнер оттуда не используется.
