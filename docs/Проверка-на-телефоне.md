# Проверка промежуточной версии ASTRA (этапы 1–3)

Это сценарии проверки, а не результаты. Модульные тесты проверяют расчёты и не заменяют запуск на телефоне. Для проб используйте тестовые дела и фото без личных данных.

| Что проверить | Ожидаемый результат |
|---|---|
| Установить APK ASTRA рядом с исходным планировщиком | Обе установки сохраняются; ASTRA не удаляет данные исходного приложения. |
| Открыть приложение, добавить дело без времени, дело на 09:00 и промежуток 08:00–08:30 | Видна сегодняшняя дата; сверху дело без времени, затем промежуток и дело на 09:00. |
| Отметить дело на 08:00 и снова открыть день | Дело зачёркнуто, остаётся на прежнем месте. |
| Перейти свайпом на завтра, добавить дело, открыть календарь и вернуться кнопкой «Сегодня» | В календаре отмечены даты с делами. Выбор даты открывает соответствующий день. |
| Попытаться сохранить промежуток 12:00–11:00 | Некорректное значение не сохраняется. |
| Выбрать фото из галереи и добавить ещё одно системной камерой | Оба снимка открываются в карточке и во весь экран. Отмена камеры не создаёт пустое фото. |
| Сохранить карточку, перезапустить приложение и открыть её без интернета | Название, время, отметка и прикреплённые фото сохранились. |
| Переключить систему между светлой и тёмной темой | Дата, время, текст и кнопки читаемы в обоих режимах. |

На следующих этапах отдельно проверяются шаблоны и правка повторов, сигналы при закрытом приложении и после перезагрузки, виджет после изменения дел и полуночи, стиль с эффектами, экспорт и импорт копии. Эти функции не следует считать готовыми по результату сборки этапов 1–3.
